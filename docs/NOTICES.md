# 알림

관리자가 "최근 업로드된 작품" 같은 소식을 올리면 방문자가 우측 상단 종 아이콘에서 본다.
그동안 카카오톡으로 보내던 것을 앱 안으로 들여온 것이다.

## 데이터

```sql
notice (id, title, body, published_at, created_at)
```

**이 앱에서 사람이 만드는 유일한 데이터다.** 나머지는 전부 Plex 사본이라 동기화로 복구되지만
이 표는 안 된다 — 백업 대상은 이것뿐이다.

`body` 는 카카오톡에 보내던 원문 그대로다. 이모지와 줄바꿈을 그대로 담고, 화면에서
`whitespace-pre-wrap` 으로 편다. 마크다운이나 서식 문법을 넣지 않는다 — 쓰던 대로 붙여넣는 게
가장 빠르고, 나중에 푸시로 보낼 때도 그대로 실린다.

## 대상

`notice_target` 이 대상 프로필을 담는다. **행이 하나도 없으면 전체 발송**이다.
종 아이콘은 "내 프로필이 대상인 것 + 전체 발송분"만 보여준다.

## 푸시

**한 행이 곧 푸시 알림 한 건이다** — `title` 이 푸시 제목, `body` 가 푸시 본문
(푸시는 200자까지만 싣고 전문은 앱에서 본다). 웹 알림과 푸시가 같은 레코드를 쓴다.

`device` 가 앱 설치 기기를, `notice_delivery` 가 기기별 발송 결과를 남긴다.
자격증명(`FCM_SERVICE_ACCOUNT`)이 없으면 발송하지 않고 `pending` 만 쌓는다 —
나중에 키를 넣으면 그대로 나간다. 자세한 건 [APP-INTEGRATION.md](APP-INTEGRATION.md).

## 화면

| 경로 | 내용 |
|---|---|
| 종 아이콘 (모든 화면) | 최근 30건. 안 읽은 수를 배지로 표시 |
| `/admin/login` | 관리자 비밀번호 |
| `/admin/notices` | 작성 · 초안 생성 · 목록 · 삭제 |

**안 읽음 표시**는 브라우저 `localStorage` 에 "마지막으로 읽은 알림 id" 하나만 남긴다.
계정이 없으니 서버에 둘 자리가 없고, 잃어버려도 배지가 다시 뜰 뿐이라 잃어도 되는 값이다.

## 권한

알림을 올리려면 관리자 비밀번호(`ADMIN_PASSWORD`)가 따로 필요하다. 열람은 프로필
이메일만 확인하고 들어오는 자리라, 그걸로 알림까지 보낼 수 있으면 안 되기 때문이다.
관리자 세션은 12시간짜리 별도 쿠키(`nuplex_admin`)이고, 서명 대상에 범위가 들어가 있어
프로필 쿠키를 관리자 쿠키로 바꿔치기할 수 없다. 자세한 건 [SECURITY.md](SECURITY.md).

## 초안 자동 생성

`/admin/notices` 의 "초안 만들기" 는 최근 N일(3 · 7 · 14 · 30) 안에 추가된 작품을 Plex 섹션별로
묶어 본문을 채운다. 이미 DB 에 있는 데이터라 Plex 를 다시 부르지 않는다.

섹션 제목 `영화 | 한국` 은 알림에서 `한국 영화` 로 뒤집고 앞에 이모지를 붙인다
(`영화 🎥` · `드라마 📺` · `애니 🔮` · `예능 🧨` · `다큐 🎬`). 매핑은 `lib/notices.ts` 의
`SECTION_EMOJI` 에 있다.

만들어진 초안은 그냥 텍스트다. 그대로 보내도 되고 고쳐서 보내도 된다.
