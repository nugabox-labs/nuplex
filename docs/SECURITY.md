# 보안

## 위협 모델

이 앱은 **인터넷에 공개된 주소에서 개인 라이브러리 목록을 보여준다.** 지켜야 하는 것은 둘이다.

1. 주소를 아는 아무나가 라이브러리 구성을 보지 못하게 한다 → 프로필 이메일 확인
2. Plex 토큰이 브라우저 · 저장소 · 로그로 새지 않게 한다 → sync 컨테이너에 가둔다

재생 자체는 Plex 가 다시 인증한다. 이 앱을 뚫어도 영상은 못 본다.

## 접근 제어

**관문은 프로필이다.** 공통 비밀번호는 두지 않는다 — 지인에게 한 값을 공유하는 방식은
누구에게 흘러갔는지 알 수 없고, 어차피 알림을 사람별로 보내려면 "지금 누가 보고 있는지"
를 알아야 하기 때문이다. 그래서 관문과 신원을 하나로 합쳤다.

| 범위 | 확인하는 것 | 쿠키 | 유효기간 | 쓰는 곳 |
|---|---|---|---|---|
| 열람 | 그 프로필의 가입 이메일 | `nuplex_profile` | 1년 | 앱 전체 |
| 관리 | `ADMIN_PASSWORD` (평문) | `nuplex_admin` | 12시간 | `/admin` · `/api/admin` |

입장 화면(`/welcome`)은 아무것도 묻지 않는다. **입장하기 → 프로필 선택 → 이메일 확인**
순서고, 통과하면 1년 쿠키가 생겨 "나가기" 를 누르기 전까지 다시 묻지 않는다.
관리자가 켠 프로필만 선택 화면에 나오고, 이메일이 없는 프로필은 켤 수 없다
(막다른 길이 되기 때문이다 — `lib/profiles.ts`).

관리자는 **아이디 `root` + 비밀번호**다. 아이디는 화면에서 고정돼 있지만 서버에서도
확인한다 — 화면에서 고정한 값은 언제든 우회할 수 있다.

**관리자 비밀번호는 평문으로만 둔다.** 자주 안 들어가서 잊지 않도록 한 선택이고,
`.env` 를 읽을 수 있는 사람은 어차피 서버에 들어와 있다는 판단이다. 해시 방식은
두지 않는다 — 경로가 둘이면 어느 쪽이 실제로 쓰이는지 헷갈린다. 대신 `.env` 는
커밋하지 않는다. 비교는 상수 시간으로 한다.

**시도 제한.** 이메일 확인(`/api/profile/select`)은 프로필 · IP 조합당, 관리자
로그인(`/api/admin/login`)은 IP 당 10분에 10회까지만 받는다. 컨테이너 하나짜리 앱이라
메모리에 센다 — 재시작하면 초기화되지만 무차별 대입을 늦추는 목적에는 충분하다.

**쿠키.**

| 항목 | 값 |
|---|---|
| 내용 | 범위(+프로필 id) + 만료시각 + HMAC-SHA256 서명 (`SESSION_SECRET`) |
| 속성 | HttpOnly · SameSite=Lax · Secure(운영) |

담는 정보가 범위와 만료시각뿐이라 훔쳐도 얻을 게 없고, 서명이 없으면 만료시각을 늘릴 수 없다.
범위가 서명 대상에 들어가므로 프로필 쿠키를 관리자 쿠키 자리에 넣어도 통하지 않는다.
`SESSION_SECRET` 을 바꾸면 모든 쿠키가 즉시 무효가 된다.

**보호 범위.** `proxy.ts` 가 입장 · 프로필 선택 화면을 뺀 전부를 막는다.
**포스터 이미지(`/media/*`)도 막는다** — 포스터만 봐도 무엇을 갖고 있는지 드러나기 때문이다.
예외는 `/media/avatars` 하나다. 프로필 선택 화면이 아직 아무 관문도 통과하지 않은
사람에게 아바타를 보여줘야 하기 때문이고, 아바타는 라이브러리 구성을 드러내지 않는다.

## Plex 토큰

- `PLEX_TOKEN` 은 `sync` 컨테이너에서만 쓰인다. `web` 은 Plex 를 호출하지 않는다
- 이미지 요청도 헤더(`X-Plex-Token`)로 인증한다. **쿼리스트링에 토큰을 싣지 않는다** —
  URL 은 로그 · 리퍼러 · 프록시 캐시에 남는다
- 유출 시: Plex 계정에서 해당 기기를 해제해 토큰을 무효화하고 새로 발급 → `.env` 만 교체

## 파일 서빙

`/media/[...path]` 는 경로를 `path.join` 으로 조립하지 않는다. 세그먼트마다
`^[A-Za-z0-9._-]+$` 를 요구하고 `..` 를 거부한다. 어차피 우리가 만든 해시 파일명뿐이라
이 화이트리스트로 충분하고, 경로 탈출 가능성이 아예 사라진다.

## 저장하지 않는 것

- 사용자 계정 · 이메일 · 시청 기록 — 애초에 없다
- 업무 데이터를 localStorage/sessionStorage 에 두지 않는다
- `.env` 는 커밋하지 않는다. NAS 배포 디렉터리에 사람이 직접 올린다
